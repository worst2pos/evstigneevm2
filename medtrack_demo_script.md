**Длительность:** 7 минут  
**Фокус:** Безопасность + Польза для пациентов  

## ТАЙМЛАЙН:

### 0:00-1:00 — ПРОБЛЕМА
"Каждый день пациенты могут не получить помощь вовремя.  
Система позволяет врачу контролировать состояние удалённо."

### 1:00-3:00 — БЕЗОПАСНОСТЬ ДАННЫХ

**Действия:**
1. Открыть панель врача (doctor1)
2. Показать анонимные данные
3. Указать на защиту данных

**Скрипт:**  
"Данные защищены и не содержат реальных персональных данных.  
Даже при утечке невозможно определить пациента."

### 3:00-5:00 — МОНИТОРИНГ

**Действия:**
1. Выбрать пациента  
2. Показать показатели  
3. Имитировать опасное значение  
4. Показать уведомление  

**Скрипт:**  
"При критических значениях система уведомляет врача менее чем за 30 секунд."

### 5:00-6:30 — ИНТЕРФЕЙС

**Действия:**
1. Показать простой интерфейс  
2. Увеличить элементы  

**Скрипт:**  
"Интерфейс адаптирован для разных возрастов."

### 6:30-7:00 — ВОПРОСЫ
"Готов ответить на вопросы, включая соответствие 323-ФЗ"
